# LexUI no projeto

Esta pasta registra a versão e as regras do Design System aplicadas ao projeto. Ela deve permanecer versionada no Git e ser lida por pessoas e agentes de IA antes de qualquer alteração visual.

Ordem de leitura: `ai/instructions.md`, `foundations/tokens.md`, `foundations/responsive.md`, `components/catalog.md` e `examples/index.json`.

Para adoção em outra aplicação, instale os pacotes e execute `npx @lexui/cli init`. Para preparar uma versão pública, siga `release.md`.
