# Padrões proibidos

- Duplicar um componente público do LexUI.
- Importar Base UI diretamente na aplicação.
- Usar `style={{ color: ... }}` ou cores literais em interfaces.
- Criar variantes como `blueButton`, `orangeCard` ou nomes ligados a aparência.
- Usar apenas cor para comunicar estado.
- Ocultar foco de teclado.
- Criar layout exclusivo para desktop.
- Alterar um componente copiado localmente em vez de evoluir o pacote central.
