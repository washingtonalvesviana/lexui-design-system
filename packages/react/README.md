# @lexui/react

Componentes React acessíveis e reutilizáveis do LexUI.

```tsx
import "@lexui/tokens/theme.css"
import "@lexui/react/styles.css"
import { Button } from "@lexui/react"

export function Action() {
  return <Button>Continuar</Button>
}
```

Use junto de `@lexui/tokens`. React e React DOM são peer dependencies.
