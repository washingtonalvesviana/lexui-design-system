# Padrões proibidos

- Duplicar um componente público do LexUI.
- Importar Base UI diretamente na aplicação.
- Usar cores, sombras ou espaçamentos literais em interfaces.
- Criar variantes ligadas à aparência, como `blueButton` ou `orangeCard`.
- Usar apenas cor para comunicar estado.
- Ocultar o foco de teclado ou criar layout exclusivo para desktop.
- Alterar uma cópia local de componente em vez de evoluir o pacote central.
